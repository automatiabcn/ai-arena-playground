# Changelog

## v1.0.0 — Initial Release (April 2026)

- Side-by-side AI model comparison (2-4 models simultaneously)
- 6 providers: OpenAI, Anthropic, Google, Groq (free), Mistral, Ollama (free local)
- 11 models with real-time cost, latency, and token tracking
- SSE streaming for live response comparison
- 32 prompt templates across 6 categories (Code, Writing, Analysis, Creative, Education)
- Comparison history with search
- Model leaderboard (fastest, cheapest, most used)
- Glassmorphism dark UI with TailwindCSS
- One-command setup: `npm install && npm run setup && npm run dev`
- Docker support
- MIT License — free and open source
